# 多链预埋配置模板（填空式）

四家链的代码路径**已全部预埋完成并通过离线自检**（不需要凭据即可验证）。这里只是"填值"的地方。

| 模板 | 链 | 存证 | 资产发行 | 典型客户 |
|---|---|---|---|---|
| `链数根.env` | 链数根（上海数据集团·联盟链） | ✅ | ❌ | 政府/景区票根存证 |
| `腾讯TBaaS.env` | 腾讯云 TBaaS / 至信链 | ✅ | ✅（需 NFT 合约） | 腾讯云生态客户 |
| `蚂蚁链鲸探.env` | 蚂蚁链 / 鲸探藏品 | ✅ | ✅（需资质+审核） | 阿里生态、联名藏品 |
| `EVM公链.env` | Polygon / Base / 自建 EVM | ✅ | ✅（ERC-1155） | 境外权益凭证 |

## 用法（三步）

```bash
cd wanderlust/api

# 1. 体检：看这家还缺哪几个变量、离线自测是否通过、必须问对方什么
node scripts/chain-preflight.mjs tbaas

# 2. 把模板里的「配置区」追加到 api/.env，填上 = 后面的值
#    （模板注释里写了每个值去哪儿申请、接口约定是什么、能力边界在哪）

# 3. 重启后验证
pm2 restart wanderlust-api wanderlust-jobs
node scripts/chain-ready.mjs --probe
```

## 三条铁律（模板注释里也写了）

1. **缺凭据绝不伪造**：任何一项缺失 → NOOP，批次停在「已打包·待锚定」，不产生假交易号。
2. **微信渠道硬禁**：藏品/权益凭证不得在小程序内引导交易（代码层 + 库层双闸门）。
3. **能力不吹**：联盟链不发资产、多数链无"按根反查"——幂等一律以本地台账 + txRef 为准。

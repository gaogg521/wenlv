## 一、快速开始

```bash
python build.py
```

输出：同目录下 `向往的自由-业务系统demo-高保真版.html`

- 只需要 Python 3，不需要 pip 安装任何包。
- 如果有 Node.js，会自动对每段内联脚本做 `node --check` 语法校验；没有就跳过，不影响构建。
- 构建完会打印：字符数、体积、`<style>/<script>/<head>/<body>` 标签配对结果、JS 语法结果。

**在另一台电脑上接手时，把这句话告诉助手即可：**
> 这是「向往的自由」原型源码包，先跑 `python build.py` 确认能构建，再按我要改的页面去改 `src/` 下对应组件，不要直接改输出文件。

## 三、常见修改场景 → 改哪个文件

| 想改什么 | 改哪里 |
|---|---|
| 某个页面长什么样 | `p6.html`（游客端）/ `p7.html`（合伙人 + 商户）/ `p8.html`（运营端） |
| 颜色、圆角、字号、间距 | 优先 `p2c.html`（新增样式追加到末尾，避免动老样式） |
| 新增图标 | `p3.html` 加 `<symbol id="i-xxx">`，页面里用 `ic('i-xxx')` |
| 线路 / 商品 / 订单 / 团队等演示数据 | `p4.html` 的 `DB`，或 `p4d.html` 的 `DB.x` |
| 四端 Tab 名称与顺序 | `p4.html` 的 `ENDS` |
| 剧本闯关可玩链路（数据/状态机/地图） | `p4.html` 的 `DB.scriptData`、`p4b.html` 的 `scriptMapSVG()`、`p6.html` 的 `play*` 函数、样式在 `p2c.html` 的 v5 段 |
| 六大引擎可玩链路（激励/贡献/结算/网关） | 数据在 `p4d.html` 的 `DB.engine / DB.contrib / DB.settle / DB.gateway`，逻辑与页面在 `p8.html` 的 `pushEnginePage()` 与 `rw* / ct* / st* / gw*` 函数 |
| 场景插画（竹林/水乡/山野等） | `p4b.html` 的 `sceneSVG()` 与各 `_fgXxx()` 前景生成器 |
| 图表（柱/环/漏斗/徽章） | `p4c.html` |
| 路由、登录、页面切换 | `p5.html` |
| 顶部状态栏（沉浸式 / 字色自动适配） | `p5.html` 的 `probeTopBg / autoSB / applySB` + `p1.html` 的 `.statusbar` |
| 新增一个子页面 | 在对应端的文件里写 `function pushXxxPage(){ return push('标题', html, {}) }`，再在入口处 `onclick="pushXxxPage()"` |
| 筛选 / 排序切换 | 用 `repaintCurrentPage(fn)` 原地重绘（`p6.html`），**不要压栈** |

### 技术约定（改的时候必须遵守）

1. **单文件约束**：不允许引入任何外部 JS / CSS / 图片 / 字体。所有插画都是运行时生成的 SVG。
2. **页面 = 字符串**：每个页面函数返回 HTML 字符串，由 `push(标题, html, opt)` 压栈；`pop()` 返回。
3. **样式用 CSS 变量**：`--ink / --ink2 / --sub / --faint / --line / --brand / --brand-deep`，不要写死颜色，否则换端会串色。
4. **图标写法**：`ic('i-home')`，不要手写 `<svg><use>`。
5. **文件编码 UTF-8**，行尾 LF。用 Windows 记事本另存会带 BOM，可能导致首行渲染异常。

### 写新走查工具时的三个坑（都实际踩过）

1. **选择器要用 `#pageStack .page:last-child`**，不能用 `.page.in` —— 页面栈动画期间新页还没加 `.in`，`.page.in` 会抓到栈底页，导致"领取后状态没变""未落地订单详情"这类假失败。
2. **固定 `sleep` 极易竞态**。`push` 有 340ms 动画，`afterOrder()` 内部还有 480ms + 400ms 的 `setTimeout` 链。写断言请用轮询等待（见 `paytrace.js` 的 `waitFor`），别写 `sleep(1100)` 就断言。
3. **快照要包含 class 与元素顺序**。只比 `innerHTML.length` 会把"排序档从综合推荐切到人气"这类**真实生效但长度不变**的切换误判为死链。`deepscan.js` 的 `sig()` 就是干这个的。
4. **已选中项（`.chip.on` / `.lseg.on`）点击本就不该有变化**，扫描时要显式跳过，否则满屏误报。

## 六、已知约束与坑（踩过的，别再踩）

1. `<style>` 必须成对闭合。历史上漏一个 `</style>` 会导致**整个页面所有点击失效**，且控制台不报错——排查时先用 `build.py` 看标签配对。
2. `.kvs` 是"一行 label + value"，**不是列表容器**。要列多行就写多个 `.kvs`，别用一个 `.kvs` 包多个 `.kv`，否则会挤成一行互相覆盖。
3. `.prog` 进度条是白底白条，放在白卡片里完全看不见，要用 `.prog.on-light` / `.prog.blue-light`。
4. `.imgwrap` 自带暗角蒙层，缩略图里用要加 `.flat`，否则会压灰。
5. `.sec-title` 是 `space-between` 布局，往标题里塞图标会被推到两端，要包一层 `<span>`。
6. 环形图 / 圆环图必须写 `style="width:Npx;height:Npx;flex:0 0 auto"`，否则被 flex 压成竖条。
7. SVG 里用 `currentColor` 时不要同时依赖 `fill` 和 `stroke` 的默认值，显式写颜色最稳。
8. **内联 `onclick` 里不能引用模板字符串的局部变量**。写 `onclick="pushNoteDetail(${ni})"` 是字面量插值（正确）；写 `onclick="foo(ni)"` 会报 `ReferenceError: ni is not defined` —— 模板变量不会成为全局变量。
9. **`$('#id')` 是全局选择器，页面栈多层时会选到底层同名节点**。子页面里的逻辑必须用 `S.stack[len-1].el.querySelector('#id')` 限定作用域（见 `filterSearch`）。
10. **不要用会重复压栈的 `oninput`**。搜索框写 `oninput="pushSearchPage(this.value)"` 会每输入一个字压一层，返回键要按十几次；应改为 `oninput="filterSearch(this.value)"` 只重绘结果区。
11. **筛选/排序切换要用原地重绘，不要压栈**。`pushCategoryPage` 检测栈顶标题相同则只替换 `.page-body` 并保留 scrollTop；通用的 `repaintCurrentPage(fn)` 就是干这个的。只重绘列表容器而不重绘整个 page-body，会导致 chip 高亮态不同步，走查会判成"无响应"。
12. **三元表达式注意括号**：`const t = S.stack.length ? (S.stack[S.stack.length-1].title || '') : '';` —— 少一对括号 `build.py` 的 `node --check` 会精准报错。
13. **状态栏是 absolute 浮层，不是流内元素**。任何"页面顶部安全区"的调整都要同时确认 `#baseScroll{padding-top:44px}` 与 `.page{padding-top:44px}`，沉浸式头部用 `.page.top-bleed{padding-top:0}` 顶格。
14. **压栈子页一律 `applySB('light')`**。`push` 出来的页面顶部是半透明白 navbar，若被 `.gal`/`.imgwrap` 误判为深底会触发沉浸，标题被灵动岛压住。
15. **`DB` 是分层的，别想当然**。`DB.budget` **不存在**，预算池在 `DB.admin.budget`；`DB.warnings` 同理在 `DB.admin.warnings`。写引擎逻辑前先用 `probe.js` 确认字段真实路径。
16. **在 p4d 及之后新增的 DB 字段，必须并入 `DB_INIT`**，否则「重置演示数据」（`resetDemo()` 用 `DB_INIT` 全量覆盖）会把新增数据清空。在 p4d 末尾补 `['engine','contrib',...].forEach(k=>{ if(DB_INIT[k]===undefined) DB_INIT[k]=JSON.parse(JSON.stringify(DB[k])); });`
17. **走查脚本里读对象要用 `JSON.parse(await ev('JSON.stringify({...})'))`**。CDP 的 `returnByValue` 对页面内对象字面量有时返回 `undefined`，包一层 `JSON.stringify` 最稳。同理避免在注入的表达式里用可选链 `?.`。
18. **断言别写成恒真**。`ev()` 遇到页面内异常返回的是 `{__err:...}` 对象（truthy！），`ok(await ev('DB.budget.used...'))` 这种字段名写错的断言会永远 PASS。enginetrace 曾因此蒙混一整轮；写断言先确认字段真实存在，比较值用显式 `===`。
19. **`textContent` 会剥掉 HTML 标签**。跨页断言里匹配 `<b>312,800</b>` 要写 `/已发行 ([\d,]+)/` 匹配纯文本，带标签的正则永远匹配不到。

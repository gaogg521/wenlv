## 一、怎么访问

**本地看**：把 `向往的自由-招商宣传站.html` 和 `向往的自由-原型源码\` 文件夹放在一起（保持同级），双击 html 用 Chrome / Edge / Safari 打开。断网也能看，不需要服务器。**只拷 html 一个文件的话，4 处演示入口会打不开**——原型链接指向旁边的文件夹。

**上线**：把这个 html 直接丢到任意静态托管（宝塔 / OSS / COS / Vercel / GitHub Pages），**单文件，没有依赖目录，不用装环境**；`向往的自由-原型源码\` 按同样目录结构一起传，演示入口才可用。建议同时配一个 `向往的自由.com` 这类短域名。

## 六、已知限制

1. **纯静态**：没有后台、数据库、登录、支付。留资靠外部表单服务。
2. **表单只在浏览器端校验**，关掉 JS 能提交空值，靠表单服务那边兜底。
3. **所有数字是示范环境实测口径，不是经营承诺**。页脚已写明「不构成任何收益承诺或投资建议，最终以签署合同为准」——这句别删。
4. **Web3 部分展示的是示范环境的合约地址与哈希**，不是主网真实交易。
5. **手机截图对应 2026-10 版 demo**，demo 改版后要重截，否则图文对不上。
6. 单文件 1.22MB（图片约 900KB），首屏 base64 解码有轻微延迟，实测无阻塞。
7. **算账工具是情景测算，不是财务模型**：只有 GMV、变现、变动/权益/固定成本四类口径，未含税费、退款损失、资本开支与融资成本；默认结论是亏损（−¥72,270）。数字可现场改，改完结果随之变，但**不构成收益承诺**。
8. **4 处演示入口依赖同目录的原型文件夹**：`向往的自由-招商宣传站.html` 必须和 `向往的自由-原型源码\` 同级放置（本地双击、上传托管都是这个规则）。只拷 html 一个文件，演示按钮会 404。
9. **demo 是演示态登录**（任意手机号 + 任意验证码即进），用于讲清交互与账目逻辑，不代表系统已上线运营或真实用户数据。

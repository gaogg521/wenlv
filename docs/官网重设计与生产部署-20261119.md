- 官网目录独立为 `/opt/wanderlust-site/releases/<release>/site`；`current` 原子切换，nginx 独立 `server_name ziyou.1work.vip`。
- 发布脚本 `招商宣传站/ops/publish.sh` 校验包 SHA256，备份 nginx 配置及原版本链接，申请独立 HTTPS 证书，`nginx -t` 后平滑重载，失败恢复原配置。
- 现有 `/opt/wanderlust/api`、`.env.production`、MySQL 卷、API 容器及其他域名配置保持原状。
- 每个发布包增加 `version.json`，记录源提交、发布编号和静态内容摘要；线上逐文件核对 SHA256。
- 证书沿用服务器现有 `/etc/cron.d/certbot-renew` 每天 03:17 续期检查及现有 reload hook。

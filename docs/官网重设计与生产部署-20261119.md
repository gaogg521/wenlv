## 生态定位与叙事重做

负责人指出：首屏野外素材仍不合适，官网缺少完整生态的市场定位。本轮参考 `向往的自由-宣传网站-验证4/index.html` 的主题、权益、身份、生态叙事，不照搬其中的示例价格、虚构评价、占位联系方式和过时技术承诺。

- 定位：主题旅行与在地生活共创平台；先讲游客为什么愿意来，再讲内容、权益与可信记录如何延长连接。
- 游客动机：参与主题故事、按兴趣找到同路人、把创作和旅行收获带入下一次出发。
- 八类可交互主题灵感：剧本探秘、她的旅行、好友社交、身心疗愈、运动户外、亲子自然、文化研学、远方探索；不宣称八类均已开售。
- 旅豆独立主区：怎样获得 / 怎样使用 / 怎样持续，解释活动审核、试算、有效期与上限、预算与账本；与自由豆分开。
- 可信凭证独立主区：出行凭证 / 旅行履历 / 可信证明，区分出行使用有效期与记录留存，核对签发来源、签名、有效与撤销状态，说明角色授权与隐私边界。
- 生态六环：内容获客、选择下单、商户体验、凭证核销、规则对账、权益回流；展示旅行者、创作者、商户和城市/推广伙伴的具体价值。
- 首屏改用晴天乌镇及国内在地文化画面，保持暖橙与动态轮播。

口径依据：现行 `api/src/domain/bean.mjs`（预算、账本、抵扣、冲正）、`pass.mjs`（订单关联与核销有效窗）、`vc.mjs`（签名、过期、吊销与最小披露）、`attest.mjs`（存证核验）。不把可信记录写成服务质量担保，也不写一号自动拥有三端全部权限。

本地 1440px / 390px / 320px 布局通过，八个主题、三种旅豆说明、三类凭证结构切换通过；图片、锚点、控制台与全量 npm test 通过。

## 回滚操作

首次上线若需撤下官网，仅恢复本次站点配置与 current 链接，不能把整份 nginx 备份覆盖回去影响其他服务。首次版本的 previous-release 为空，可移除 `/etc/nginx/conf.d/ziyou.1work.vip.conf` 后执行 `nginx -t && nginx -s reload`；证书和发布目录保留以便重上。

后续回滚到已验收版本：将 `/opt/wanderlust-site/current` 原子指向上面的发布 site 目录，使用对应 release 的 `ops/ziyou.1work.vip.conf`，通过 `nginx -t` 后重载。原 API、MySQL、数据卷与配置不参与官网回滚。

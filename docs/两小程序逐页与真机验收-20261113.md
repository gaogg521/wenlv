## 实页验收顺序

1. 游客端用真实微信登录，走首页、团期、详情、预订、支付结果、订单与动态凭证。MOCK 支付结果只记联调，实际付款单独登记。
2. 游客端补目的地、商城、内容、任务、个人页、旅豆/自由豆、S/R 成长明细和推广分享。覆盖未登录、授权拒绝、空态及返回。
3. 商户端使用真实门店身份，走工作台、订单详情、库存、核销、结算和回单。分别验证店长与核销岗、跨店拒绝、相册拒绝、弱网与重复核销。
4. 微信预览后分别扫游客端与商户端预览码，记录机型、微信版本、入口、订单号及截图，回填每页两列。体验版按公网 HTTPS 域名及合法域名配置复验。

CLI 实际尝试自动编译：游客端返回 APPID_ERROR／需要重新登录；商户端项目使用 touristappid，返回 APPID_ERROR／不存在此 AppID。商户端真实 AppID 需写入授权联调配置。两个项目均未进入模拟器，真机预览未生成。

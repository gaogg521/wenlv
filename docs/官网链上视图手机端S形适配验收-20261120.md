## 一、需求与基线

负责人反馈：手机版六步立方体横排成长条、需左右滑，建议按浏览器宽度自动折成 S 形。

基线实测（390 宽）：`.cv-steps` 为 flex + `overflow-x:auto`，六格横排，第 6 格起点 679px，远超 390 屏宽，只能看到 01/02 和半个 03。

## 二、改动内容（仅 `site/editorial.css`，纯响应式）

- **≤760px**：六步链由 flex 横滚改为 `grid` 3 列 2 行；第 4/5/6 步用 `grid-column:3/2/1` 反置到 右/中/左，与第一行 01→02→03 构成 S 形（蛇形折返）。
- **折返连线**：第一行向右（原虚线/数据包保留）；03→04 同列竖直下折（新增 `cvPacketDown` 动画）；第二行 04→05→06 从右向左（新增 `cvPacketLeft` 反向动画）。
- **760–900px** 保持原六列横排（宽度足够，无需折行）；>900px 不变。
- 窄屏批次标签收紧字号/内边距（`≤360px` 再降一档），保证单行不拆字；扫描光带覆盖两行。
- SVG 立方体形体、文案、桌面布局一律未动；纯 CSS + 已有 CSS 变量，无内联样式、无 JS 写入。

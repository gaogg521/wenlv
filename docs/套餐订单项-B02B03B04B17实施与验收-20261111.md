## B04 资金契约 v1（已落码，全部可复算）

1. **唯一主单**：套餐订单仍是一张 orders 主单（一个 order_no、一笔 amount_pay、一条支付流水）；order_items 是履约与对账维度，不产生第二笔支付。
2. **三路同口径占比分摊**：现金 X＝G−C−B、自由豆券额 C、旅豆 B 各按项原价占比 floor 分摊，**尾差归最后一个正额项**；Σcash=X、Σsubsidy=C、Σbean=B 恒等（断言验证）。早鸟/折扣先作用于整体 G，再按比例缩到项（Σ项原价=G 恒等，断言验证）。
3. **成本不占比**：项成本 = 该项挂的供给项成本（unit_cost×qty_per_unit×人数）独立快照；订单级 cost_total 仍由 product_supply 计算，两者是两个清晰视图，无重复计费。
4. **部分退款**：仅未核销项；实退＝Σ项现金分摊−政策手续费（游客自助按梯度，客服/超管平台原因免手续费）；旅豆/券不冲回（全退才走既有冲回）；被退项凭证同步冲正；订单状态不变；**全退恒等：fullRefund 退"实付−已结算部分退"，Σ退款=实收现金**（断言验证）。冲减进 partial_refund + refunds（PR前缀），经营看板净销售额/成本按项冲减。
5. **不得无来源追加成本、不得原价分账后再额外付补贴**：补贴责任始终挂 freedom_order（订单级），项级 subsidy_fen 只做对账维度。
6. **部分完成不提前发奖励**：返豆/佣金仍在订单级完成后发放；存在未履约项时单项凭证核完不触发 VERIFY_ALL（状态机守卫，断言验证）；服务项完成最后一项才推进核销完成。

## 契约算例（专项精确命中）

- 199 元商品（门票 12000 按人凭证 + 讲解 7900 服务项，跨两店）、满100减50 → 实付 14900：**门票现金分摊 8984、讲解 5916**（floor(14900×12000/19900)=8984，尾差归讲解）；补贴分摊 3015/1985（Σ=5000）。
- 部分核销后退款：核销讲解项后退未核销门票项 → **退 8984**（已核销项被拒）；Σ退款=实收 14900（8984 部分退 + 5916 全退）。

## 保留的既有守卫

- 跨店隔离（凭证/服务项按归属店核销，非本店拒绝）、防重放（动态码窗口+重放拦截；服务项幂等键唯一）、并发（项状态 FOR UPDATE 守卫，双幂等键并发只成功一次）、名额与关单流程不变、补贴订单禁止后台改期调价守卫未触碰。
- 历史无项订单完全走原路径（issuePassesInTx 分支保持）。

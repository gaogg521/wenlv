## 3. PC 后台经营测算

来源为主工作区 `招商宣传站/向往的自由-招商宣传站.html` 的 `#calc` 与配套脚本。截图为相邻的招商等级说明，作为第 2 项参考。PC 后台新增完整算账模块，授权给城市合伙人、商户、景区的对应身份。复用已有身份和主体授权，商户和景区的 PC 入口及主体映射需交付实测。手填的情景可独立计算，若接入实际数据或保存方案，按授权城市/门店/景区和主体隔离。显示测算主体视角，招商原模型的“平台月收入”只用于平台视角，商户、景区或合伙人的收入依对应有效合同或明确手填假设展示。测算结果用于情景比较，与实际账单、分润和毛利看板口径明确区分。

完整移植六项可编辑假设（订单量、客单价、综合变现率、变动成本率、权益成本率、固定成本）、恢复示例、月 GMV、收入、两项成本及合计、固定成本、经营贡献结余、单笔贡献、盈亏平衡单量及状态说明、四条单变量达标路径、3×3 客单价与单量敏感性表及图例。允许精确输入金额和费率，敏感性网格用同一计算函数并标明真实轴值与状态，避免仅用颜色区分。

公式中 N 为月单量，P 为客单价，F 为固定成本，m＝变现率−变动成本率−权益成本率。GMV＝N×P，收入和两项成本各按 GMV 乘相应费率，单笔贡献＝P×m，结余＝N×P×m−F。用整数分与整数基点计算，规定内部精度、结果分级取整及汇总尾差。盈亏平衡单量取满足结余非负的最小整数。当 F＞0 且 P×m≤0 时，提高单量无法达到平衡。零固定成本与零贡献也要有明确结果，不出现 Infinity、NaN 或“多卖必多亏”的错误提示。

四条路径只改变指定参数。最低客单价按分向上取整，最低变现率按支持的比例步长向上取整，固定成本上限按分向下取整，最低单量向上取整。回代验证每个临界值，必要时标记目标超可选范围或分母为零。原页面主结果用 Math.round 取平衡单量、变现率目标四舍五入，需在后台实现中纠正。敏感性表以未格式化的计算结果判定正负，并处理零订单、零客单价、重复轴值及费率边界。

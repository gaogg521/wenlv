# 商户金属授勋奖牌重设计

用户明确否定房屋造型和暖色扁平认证牌，要求铜、银、金、钻石、黑金的奖牌层次。本次以新图稿替换商户等级认证主图：金属厚度、八芒浮雕、月桂、缎带与钻石镶嵌，不再出现房子、屋檐、门店或拱形牌匾。

使用内置 imagegen 制作五张独立透明PNG；后四张以铜牌原图为参考保持系列构图。最终原图已保存至 `api/assets/merchant-medals-20261108/{bronze,silver,gold,diamond,blackgold}.png`，完整提示词与生成方式见该目录README。原图保留，不做额外创意后处理。

原有四档经营等级及门槛未变，对应铜、银、金、钻石。黑金图稿在徽章管理新增的五材质预览中可见，尚未绑定第五个经营等级，不新增任何商户资格或发放记录。游客等级图不变，商户其他经营荣誉的业务含义不变；旧store图形回退改为星形，避免再次出现房屋主图。

接入原有 `/badge-art` 统一渲染，PNG按显示尺寸输出，未获得保持灰阶弱化。管理页等级与商户认证列表改用PNG以免嵌入大图的SVG增加传输，B端首页等级简讯、等级/荣誉页同步新版本参数。自定义上传图仍优先。没有改订单、账本、密钥、等级规则或可信状态。

验证项：五款材质可独立选择；现有四档没有被扩成五档；五款已获得/未获得可渲染64px PNG；全类图形、未知图标回退、PNG字体扫描优化及游客图形隔离保持回归。完成代码测试后同步演示并追加后台及模拟器实查。

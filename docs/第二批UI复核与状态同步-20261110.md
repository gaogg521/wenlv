# 第二批UI复核与状态同步

变更：[PR #166](https://github.com/gaogg521/wenlv/pull/166)。第一/二批业务完成状态不变，本PR为界面与状态收尾。

负责人指出三处问题：授权弹窗的门店/岗位控件挤在一起、运营金额输入误用“分”、预订页补贴名称和满减说明重复并断行。本轮针对这些问题修正，不重新实施已完成的第一、第二批业务。

## 修正

- 主体授权弹窗拓宽，分为「主体与档案 / 合作经办 / 门店岗位 / 授权记录」。统一选择框、标签、按钮间距；门店与岗位并排，窄屏改为上下布局，停用操作单独呈现。保存后保留用户、门店、岗位及当前标签页，不再跳回初始表单。
- 销售授权、自由豆规则/预算/发放/回单表单统一两列栅格、关联标签、同组日期与限额；长字段独占一行，记录状态改为中文。
- 自由豆预算、消费门槛、减免和实际付款/追回，运营统一按「元」输入/回显。默认直接显示100.00和50.00。提交时使用十进制字符串精确转换为整数分，拒绝超过两位小数、0、负数及超限，不用浮点乘法猜金额；服务端和历史数据仍为整数分。
- 游客预订页将补贴拆为独立区域：标题＋选择/更换，下一行只显示一次「满100元减50元」，右侧显示减免金额；有效期和与旅豆互斥说明另起行。旅豆余额/抵扣上限也移至说明行，不再和开关抢宽度。

## 2. 你验收时跑什么

全新隔离库 + 隔离服务（端口自选，如 18240）：

```bash
cd api
node --env-file=<你的隔离环境文件> scripts/migrate.mjs          # 或 DB_NAME=... node scripts/migrate.mjs
DB_NAME=wanderlust_qa_<x> PORT=<端口> API_BASE=http://127.0.0.1:<端口> npm run seed:scenario
npm test                                                        # 含 A-05/A-18/A-19/A-22 静态守卫
DB_NAME=wanderlust_qa_<x> PORT=<端口> API_BASE=http://127.0.0.1:<端口> npm run test:db   # 含三批 60 项新断言
DB_NAME=wanderlust_qa_<x> PORT=<端口> API_BASE=http://127.0.0.1:<端口> npm run test:chain
```

**注意（两次踩过）**：
- seed/测试必须**先起隔离服务**并显式固定 PORT+API_BASE，否则 HTTP 调用打进 8080 演示库（本次交付过程发生过一次，已全量还原+复盘）。
- `test:db` **不能对同一库重复跑**：日终根 force 重封会撞"该日根已提交上链"守卫（attest.mjs 既有保护）。每个全新库跑一遍即可。

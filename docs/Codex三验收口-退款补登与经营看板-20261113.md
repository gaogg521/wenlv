# 三验退回项收口

Codex 接手 #198 记录的三项退回。8080 维持现有验收版。

| 事项 | 实现与独立验证 |
|---|---|
| R3 多提供方补登 | 补偿按退款选中的订单项、结算行和提供方匹配缺失调整，排除金额取整为零的项。模拟一家已登记、另一家缺失，连续执行后两笔准确为 −6960 分和 −4582 分，各一条。 |
| R2 景区首页汇总 | 首页、结算列表和 CSV 共用景区结算投影。新单优先使用订单的景区快照，旧单回退到商品归属。故意插入关联商户一张无本景区行的 ¥600 已付款账单，三处均不计入，首页结算数和金额保持原值。景区已付数字是按授权行和账单比例的投影。 |
| UX05 两类主体看板 | 复用经营分析的六滑块、四路径、敏感性与朱家角示例。Chrome 分别登录商户和景区，操作示例和恢复，核对 ¥4,041 与 ¥72,270，并打开两类明细测算弹窗。商户测算强制带入绑定商户，只可取关联景区，成本和佣金内部字段不下发。 |

本次验证在隔离环境完成。两个小程序逐页与真机、真实通道、业务资料及商户商品写权限开放范围仍沿原台账处理。S/R 和成长值仅回归。

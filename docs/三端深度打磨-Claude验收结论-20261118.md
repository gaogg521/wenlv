**设计要求**

1. 每个页面为「无资格 / 暂无数据 / 加载失败」三种情形分别设计，不得复用同一句空文案。
2. 无资格页要回答三个问题：这是什么、为什么现在不能用、怎么开通（具体联系方式或申请入口；没有入口就明说「由平台运营邀请开通」并给出客服入口）。
3. 可以展示权益预览：例如推广中心展示分成规则示意、合作中心展示可合作的主体类型，让用户知道开通后能得到什么；示意内容必须标明「示例」，不得伪装成真实数据。
4. 沿用游客端现有设计体系，不新增色板；375px 宽度下首屏内不留超过半屏的空白。
5. 所有按钮都有实际作用，权限类问题不给「重试」。
6. 红线照旧：小程序里不出现区块链和虚拟资产用语；新增页面或文案字段登记 `MINI_MAP`。

**验收**：GLM 交付后，Claude 用不同资格的账号（纯游客、推广员、合作经办）逐页在模拟器截图验收；每个页面的三种情形各一张；首屏空白占比、按钮作用、红线用语逐项检查。商户端（mini-b）同样排查一遍无权限与空态页面，并交一份清单。

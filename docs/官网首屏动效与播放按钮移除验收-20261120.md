# 官网首屏动效与播放按钮移除验收（2026-11-20）

## 负责人反馈与处理

负责人指出首屏右下角圆形播放/暂停按钮无用，要求整个首屏增加动态效果。处理口径：**删除无用控件，不换图片、不改文案、不动已认可的形体**，只在原首屏上加克制的动态层。

## 改动内容（PR #272）

- `招商宣传站/site/index.html`：删除 `.hero-transport` 整块（播放/暂停圆按钮、上一幅/下一幅箭头、01/04 计数器）；保留四条文字进度导航与图注。
- `招商宣传站/site/app.js`：删除播放按钮与前后箭头监听；轮播改为常驻自动播放，点击文字导航后立即继续计时，不再永久暂停；图注切换时重播淡入（class + 布局读取，不写内联样式）。
- `招商宣传站/site/editorial.css`：新增首屏动态层——
  - 图片 18s 缓慢漂移缩放（Ken Burns，`hero-drift`）；
  - 16s 柔和流光（`hero-glow`）；
  - 标题暖光呼吸 6s（`hero-title-breathe`）；
  - 6.5s 进度条同步填充（`hero-progress`，浅灰底 + 橙色填充）；
  - 图注淡入（`hero-caption-in`）。
- 严格 CSP 兼容：不在 HTML 写 `style`、不在 JS 写 `element.style`；`prefers-reduced-motion: reduce` 下上述动效全部关闭，进度条直接显示满格。

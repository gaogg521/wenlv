# 商户首页暖色与层次调整

用户反馈B端首页不如A端精致，常用服务与平台公告像提示按钮。问题是重复使用浅紫底、圆角和边框，主操作、功能入口与内容资讯缺少视觉区别。

本次将首页改为暖米白纸面、深林绿经营卡、陶土橙核销主操作；四个日常服务改为两列独立入口，使用不同的柔和图标底色、用途说明与轻量箭头。公告移到趋势之后，采用上下分隔线、资讯眉题与文字展开入口，去掉按钮式外框。评价采用浅米色内容区，成长入口保持轻量列表。首页导航仅在home状态使用暖色，其余页面保持原有样式。

只改WXML/WXSS，不改接口、订单数据、权限或小程序AppID。四个常用服务路由、核销、成长入口、日期切换与公告展开收起保留原处理逻辑。

验证：npm test退出0，官方wcc编译全部B端WXML通过。开发者工具模拟器连接实际8080演示服务，确认四个服务入口分别进入订单/库存/结算/核销记录；公告展开和收起正常；近30日趋势仍返回30日；核销员布局仅显示两个有权入口，无脚本异常。截图使用临时商户副本借游客AppID，不代表正式B端AppID或真机验收。

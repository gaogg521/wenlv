# 商户端全页暖色统一

订单、库存、结算、经营等级、勋章、可信凭证和我的统一为暖米白纸面、林绿标题与分组、陶土色金额和主操作。共用导航及底部选中态同步；关联订单详情、核销记录继承暖色，避免跳转后突然回到紫色。库存分组、搜索、日期/状态筛选和六条分批展开保留。

订单待接待、核销/完成与退款使用不同底色并保留明确文字；结算待确认、处理中、已登记回单和异议各有状态色。五项分账图与图例同步换色，没有修改金额、比例或确认/到账口径。已获得勋章以暖金细边强调，未获得和待确认凭证仍按原状态展示。

验证：npm test、merchant-navigation、merchant-catalog退出0，官方wcc编译全部B端WXML通过。实际8080服务下，开发者工具逐页走查订单搜索/分页、库存折叠/展开/搜索/历史/重置、账单展开和逐单明细、等级/勋章/凭证页签、我的凭证入口及历史核销记录，无脚本异常。实际点击自定义返回按钮，确认订单详情回订单、订单回工作台、结算回我的、荣誉回我的。只改展示样式及状态类名，无接口、数据库、权限或AppID变更。

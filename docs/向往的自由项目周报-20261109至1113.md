## 当前待验与依赖

- 两个小程序共 35 页已核对路由、源码和后台映射，关键静态专项通过。微信开发者工具仍等扫码，模拟器和真机逐页证据待补；两端体验版与正式版 API 域名仍需配置，商户端独立微信登录凭据缺失。
- SMTP 五项旧记录无法解密，需原主密钥或重新签发凭据。8080 仍为 MOCK；真实小程序收款、原路退款和商户／推广到账需要商户资质与通道配置、授权的低额联调以及微信或银行对账证据。
- 完成外部条件后，按台账补模拟器、真机和真实资金终态。三端其余 UX 页面、真实景区/合同资料及商户商品写权限范围继续按原台账处理。

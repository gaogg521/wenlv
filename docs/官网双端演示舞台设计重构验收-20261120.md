# 官网双端演示舞台设计重构验收（2026-11-20）

## 一、需求
用户反馈：双端小程序视频做得不错、予以保留，但承载视频的「产品演示舞台」整体设计单薄差劲，要求改进设计，并在视频基础上加简洁宣传介绍语。

## 二、改造前问题（截图诊断）
原右侧演示区 = 米色圆角块 + 双层同心圆 + 倾斜手机 + 两个白色飘气泡（"订单与履约，一眼有数"/"安心接待每一位来客"）：
- 信息层次浅，只有一句 11px 的 caption 小字，缺少品牌宣传语
- 同心圆装饰老旧、与"清新高雅大气"的整体调性不符
- 两个飘气泡只有一句话、无主次，视觉权重不足

## 三、改造方案（保留视频，只重做舞台）
1. **背景**：暖白→浅杏径向渐变 + 聚光光晕（`radial-gradient`），去掉双层同心圆，只保留一圈细光环；商户端用更冷的灰杏渐变区分。
2. **竖排宣传标语**（新增）：serif 竖排中文，游客端"世界就是我的游乐场"、商户端"把时间留给好好接待"；上方配英文 kicker（TOURIST/MERCHANT · 端名）。
3. **序号说明卡**（替代旧飘气泡）：圆形序号 01/02 + 主标题 + em 副标题（如"待接待 · 核销 · 对账"），半透明毛玻璃卡片，信息层次清晰。
4. **底部演示引导条**：带呼吸圆点（CSS keyframes，prefers-reduced-motion 降级）的胶囊提示"点击手机底部菜单切换演示"。
5. **响应式**：≤800px 缩小字号与卡片、标语限高；≤560px 隐藏副标题避免挤压。

## 四、严格约束
- 生产 CSP `style-src 'self'`：所有样式写入 `editorial.css`，HTML 无内联 style、JS 无写 style。
- 呼吸动画仅 CSS keyframes；`prefers-reduced-motion` 下关闭。

## 五、本地验证
- 三视口（1440/390/320）截图确认：竖排标语、序号卡、底部提示条排版清晰，无溢出；移动端首轮发现的"提示条溢出/序号卡挤压"已修正后复验通过。
- `ratioMatch:false` 为手机 `rotate(-3deg)` 外接矩形失真的假阴性；CSS `aspect-ratio:390/830` 与视频 390×830 实际一致。
- `ERR_FAILED` 为 file:// 下字体 CORS，本地特有，生产 HTTP 不存在。

# 官网可信凭证区重设计验收（2026-11-20）

## 负责人反馈与处理

负责人指出：底部「可信，不等于公开你的隐私。」与「不发行任何可交易资产。」两段说明虽然左右排列，却只占右栏、左半边大片空白；并要求整个可信凭证模块必须体现科技感。

处理口径：**保留已认可的身份卡、四系列 Tab 与下方链上视图主体形态**，只调整信息架构与视觉语言；不引入外部脚本，不伪造链上数据。

## 改动内容（PR #275）

- 在区块头与两栏之间新增深色 **CREDENTIAL PIPELINE 凭证流水线**：
  - 五个节点 `DID 数字身份 → 履约事实 → SHA-256 哈希指纹 → 蚂蚁链批次锚定 → 公钥离线验签`；
  - 节点连线、状态脉冲、等宽字体哈希轨迹（`sha256:… → root:… → block #…`）；
  - 明确标注「演示数据 · 口径同后台」「示意，仅展示字段形态」，不把示意值伪装成真实哈希或区块号。
- 两段边界说明从右栏内部移出，改为**跨整行的左右两张卡**：新增 `BOUNDARY 01 / 隐私`、`BOUNDARY 02 / 资产` 编号与状态竖线，文案原样保留。原截图里左侧空白的问题消失。
- 四层台阶序号由圆形改为切角方形，标签加绿色状态点；身份卡叠加一道低对比扫描光（holographic sheen）。
- 严格 CSP：无 HTML 内联 `style`、无 JS `element.style` 写入；`prefers-reduced-motion` 下新增动效全部关闭。
- 手机端五个节点自动两列换行（最后一节点居中），无需横向滚动即可看全。

## 本地验收

- `node 招商宣传站/ops/check-photography.mjs`：24 槽位全部通过（本轮未改图片）；`node --check app.js` 通过。
- CDP 精确视口量测 1440 / 390 / 320：`scrollWidth-innerWidth=0`，三档均无横向溢出。
- 带生产同款 CSP 的验证页无内联样式违规；流水线、边界卡、身份卡、四层台阶、链上视图截图逐项确认无重叠/裁切/黑块。

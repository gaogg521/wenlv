## 0. 执行纪律（照交接文档第 0 节）

1. **本脚本默认只输出核对清单，不带 `--apply` 不写库。**
2. **8080 演示库（wanderlust）不直接执行**。先在隔离库（`wanderlust_qa_*`）跑通并逐项复查，负责人同意后，在 8080 按「完整备份 → 执行 → 行数核对 → 复查」流程操作。
3. 执行前备份：`mysqldump -uroot -p wanderlust > backup/wanderlust-pre-demofix-<日期>.sql`，记录备份路径于本文件 §3。
4. 脚本守卫：`assertIsolatedDb`（DB_NAME 未设或为 wanderlust 时退出 2；CI 容器用 `ALLOW_DESTRUCTIVE=1`）。
5. 全部修正写 `audit_log`（actor=`system:demo-fix-20261117`），可逐笔追溯。

# 官网演示舞台宣传语艺术化与分栏目主题色验收（2026-11-20）

## 需求
用户反馈：说明卡仍是「01/02 圆形数字」，宣传语字体单调；要求艺术字体、不同栏目换不同颜色与展示特效、编号换成更炫酷的样式。

## 改动范围
仅官网静态站三文件：`招商宣传站/site/index.html`、`editorial.css`、`app.js`（另新增回归脚本 `api/test/verify-art-copy.mjs`）。

### 1. 编号徽标 → 几何符号
- 说明卡 `01/02` 圆形数字，改为几何符号并按栏目轮换：
  - 游客端：`✦❖ / ◈✧ / ◆◇ / ✳✦ / ◉◈`
  - 商户端：`✦❖ / ◆◇ / ◉❖ / ✳◇`
- 圆形改六边形 `clip-path`，配主题渐变色 + 浮动动画 `markFloat`，说明卡顶部加随主题色变化的渐变描边线。

### 2. 宣传语艺术字 + 分栏主题色
- 字体在楷体 / 行楷书法体之间交替（第 2、4 栏用 `STXingkai` 行楷）。
- 渐变填充 `background-clip:text` + 柔光 `drop-shadow` + 切栏淡入动画 `sloganIn`。
- 通过 `data-stage` 属性驱动 5 套（游客）/ 4 套（商户）CSS 主题变量 `--stage-a/b/c/glow/line`：赤陶 → 青绿 → 琥珀 → 紫罗 → 靛蓝；栏目标签、说明卡描边、徽标、底部呼吸点同步变色。

### 3. 竖排排版修复
- 竖排标语在 `max-height` 与「行高 × 字数」接近时会折成两列、末字被说明卡遮挡。
- 调整：桌面字号 28 / 行高 1.12 / 字距 .06em / max-height 360，底部说明卡 `bottom:12%`；移动端 max-height 280（800px 段）/ 260（560px 段）。已验证 9 字标语在桌面与 390 手机视口完整单列。

## 严格 CSP 兼容
生产 CSP `style-src 'self'`（无 unsafe-inline）。改动全部使用外部 CSS 类、CSS 变量、DOM `textContent`/`setAttribute`，无 HTML 内联 `style`、无 JS `element.style` 写入。验收在注入生产同款 CSP meta 的页面中进行，内联样式计数 0。

## 验收结果（`verify-art-copy.mjs`，file:// + 生产 CSP meta）
- 游客端 5 栏、商户端 4 栏：`data-stage`、标语文案、字体族、主题色 `--stage-a`、徽标符号、六边形 clip-path 全部随栏目正确切换。
- 1440 桌面与 390 手机：标语完整单列无裁切、说明卡无溢出、横向溢出 0。
- 控制台仅两类无害提示：meta 方式下发 CSP 时 `frame-ancestors` 被忽略（生产用 header 下发，无此问题）、file:// 下 woff2 字体 CORS（生产同源加载，无此问题）。无真实 JS/CSP 错误。
- 注意：本地验收必须用 `file://` 或 nginx，Python `http.server` 不支持 HTTP Range，会导致视频无法 seek、栏目状态不切换。

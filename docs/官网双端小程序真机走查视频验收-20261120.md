## 二、本次实现

### 2.1 真机帧抓取（miniprogram-automator）
- 环境：微信开发者工具已登录，`cli.bat auto --project <mini> --auto-port 9421/9422` 开启自动化通道。
- mini-a 用真实 AppID `wx0103e7893d828452`；mini-b 为测试号 `touristappid`（CLI 不支持），**临时**改用同一合法 AppID 开通道，抓完立即还原，配置未留改动。
- 用 `mini.switchTab()` 切菜单、`mini.pageScrollTo()` 真实滚动（验证 1400 被页高限制到 1020，确实到底），`mini.screenshot()` 抓帧。
- 抓帧返回 base64 字符串，需 `Buffer.from(raw,'base64')` 写入（直接写会损坏）。
- 累计抓取 37 帧：菜单 5+4 个、长页顶/中/底滚动、二级功能页 8+6 个、详情页 2 个。

### 2.2 完整走查流程（用户明确要求的"点进去看"）
游客端 16 帧：首页 → 主题游(顶/滚/底) → **点进第 1 条线路详情**（朱家角剧本游 ¥298）→ 商城(顶/滚/底) → 笔记(顶/滚/底) → **点进第 1 篇笔记详情**（含评论）→ 旅豆(100 旅豆/等级/账本) → 创作中心 → 数字身份 → 我的。
商户端 10 帧：工作台 → 订单(顶/滚/底) → 结算对账 → 记录核验 → 经营荣誉 → 库存 → 扫码核销 → 我的。
每帧叠加顶部栏目名 + 底部功能字幕（ffmpeg drawtext 思路，用 PIL 预合成，微软雅黑 jsyh），画布 372×900。

### 2.3 视频合成
- ffmpeg concat demuxer，每帧 1.8s，24fps，H.264 CRF 23。
- 双格式：`webm`(VP9) + `mp4`(H.264)，HTML `<video>` 用 `<source>` 按浏览器能力选择。
- 产物：`mini-a-walk.webm/mp4`（30.6s，631K/719K）、`mini-b-walk.webm/mp4`（19.8s，168K/204K）。

### 2.4 官网集成
- 两个 `.phone` 演示器内由"逐帧 DOM 复刻"改为 `<video autoplay muted loop playsinline poster>`。
- 底部透明 tab 热区：点击 seek 视频到对应功能时间点（`data-seek`）；视频播放时 `timeupdate` 反向高亮当前菜单。
- IntersectionObserver：进入视口才播放、离开暂停、页面隐藏暂停（省流量、不空跑）。
- **修正用户反馈的"鼠标动一下就暂停"**：删除原来点击后 `holdUntil = now+9000` 的 9 秒冻结逻辑，点击不再打断播放。
- CSP：`default-src 'self'` 覆盖 media-src，同源视频可播；无内联 style、无内联 script。

# 官网双端小程序演示视频：清晰度与流畅度重录验收（2026-11-20）

## 一、问题与根因
赵老师反馈两点：
1. **商户端画面分辨率差**——旧视频帧里是「手机套手机」：外层橙色模拟器外壳 + 内层小程序页面，真实内容被缩到很小。
2. **两个视频像幻灯片**——旧视频标称 24fps，但实际是每 0.5~2 秒抓一张静态截图，播放器只是在重复同一帧；automator 的 `screenshot()` 单次耗时约 1.35 秒，根本做不到连续帧。CDP `Page.startScreencast` 在微信开发者工具中不支持。

## 二、解决方案：真录屏 + 自动操作时间线
- **抓屏**：Python `mss` + DPI 感知（`SetProcessDpiAwareness(2)`），从 1920×1200 物理屏裁切模拟器区域 `770,170,1160,1000`，得到 **390×830 原生像素**（比旧版 372×803 更清晰，且无模拟器外壳）。
- **抓屏性能**：mss 实测 19.7~19.9fps（PIL ImageGrab 仅 10~12fps，已弃用）。
- **自动操作**：`automator` 按时间线执行 switchTab / navigateTo / pageScrollTo（带 duration），真实连续滚动 + 进二级页；招帧与操作由同一 Node 脚本编排对齐。
- **合成**：ffmpeg JPEG 序列 → H.264 MP4（crf20）+ VP9 WebM（crf33），按实测帧率合成避免快放。

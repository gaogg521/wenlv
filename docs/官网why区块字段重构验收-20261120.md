# 官网 why 区块字段映射重构验收（2026-11-20）

## 负责人反馈与处理

负责人指出「为什么来向往的自由？」区块文案解释不对，且看不出与导航字段（主题体验 / 旅行笔记 / 旅豆生态 / 可信凭证 / 合作共建）的关系，要求重构。处理口径：**不换原图、不改导航**，把感性叙事改为「字段 → 理由 → 板块」的清晰映射。

## 改动内容（PR #273）

- 三张卡片顶部新增字段徽章：`01 主题体验` / `02 旅行笔记` / `03 旅豆生态`，各自 CTA 指向对应板块锚点（`#themes` / `#stories` / `#rewards`）。
- 重写三条解释文案，与真实板块功能对齐：
  - 主题体验 —— 按兴趣选主题，在真实场景做任务、遇同好；
  - 旅行笔记 —— 先读真实表达与细节，再发布图文/视频/攻略图成为他人灵感；
  - 旅豆生态 —— 合格作品/活动参与/合规消费按规则累积旅豆并在适用消费抵扣，来源可查、门槛明写（原文混入「参与成为履历」，那是可信凭证范畴，已移除）。
- 区块顶部说明改为「三个理由，对应站内三个板块」。
- 区块底部新增**五板块导览条**，把导航五个字段全部串起并可直接点击跳转，明确「可信凭证 / 合作共建」在下方板块。

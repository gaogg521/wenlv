**口径先定义再实现，至少区分下列层次：**

1. 商品经营毛利＝同口径商品净销售额－对应直接采购/履约成本；毛利率＝毛利÷商品净销售额×100%。商品净销售额采用明确的实际成交/退款冲减口径，保费及代收款不算销售收入，退改手续费单列。预计成本只能计算“预计毛利”，不能伪装成已确认利润。
2. 平台经营收益还要解释推广佣金、服务费用、支付手续费、共创分润、平台承担的补贴及其他已知直接经营费用。先明确平台是销售主体还是代理及各项费用承担方，通过“收入→成本→费用→收益”的资金桥表核对；同一项已在分账或直接成本扣过，就不能再扣第二遍。**五口径中的留存金额、GMV都不等于平台净利润。** 未覆盖税费、工资、房租及全部期间费用时，只称“经营收益/已知费用后收益”，不冒充公司最终净利润；收益率必须说明分母。
3. 自由豆199减50，现金149及官方补贴50分列。平台自己承担的补贴不能同时当额外销售收入；若特定商户按合同另享补贴应收，按该主体单独列示应收/已付和资金来源，不混入平台口径，也不重复计算成本。是否纳入某主体收入及分摊依B04明确规则，不能为了毛利率好看随意切换。
4. 成本缺失显示“未维护/不可计算”，不得默认为0；真实零成本须有明确依据。净销售额为0时毛利率显示“—”；负毛利保留并提示。汇总毛利率＝合计毛利÷合计同口径净销售额，不能直接平均各订单毛利率；含税/未税、订单状态及统计时间口径一致并写明。
5. 历史订单按创建时成本/售价/优惠/费率及规则快照复算；新成本不覆盖已售历史。确认成本变化、部分退款、已结算/已付后的变化走有来源的调整记录。现金毛利、补贴责任及经营收益分别对账。
6. 成本和利润只对已授权的平台经营/财务身份及相应范围开放；普通游客、推广员不得看到采购成本，合作方/商户只见自身允许范围，不能拿完整平台利润接口直接复用。

## 一、需求与约束

负责人反馈：给六步立方体链加科技感光效，但强调「不要破坏这些区块」。

硬约束（沿用本项目既定口径）：
- 立方体 SVG 顶点 / 线框形体、文案、布局一律不动，只做叠加光效。
- 严格 CSP（`style-src 'self'`）：无内联 style、无 JS `element.style` 写入。
- `prefers-reduced-motion` 下自动降级。

## 二、改动内容（仅 `site/editorial.css`）

三处纯 CSS 叠加光效，全部沿用节点已有的 `--cube` 色与 `--i` 序号变量：

1. **节点柔光晕** `.cv-cube::before`：立方体背后的径向柔光，按节点色着色，按 `--i` 错相位（0.32s 递增）依次呼吸，形成「六步依次激活」的节奏。
2. **底部能量光柱** `.cv-cube::after`：从立方体底面向上收束的 3px 细光，与光晕同相位。
3. **数据总线扫描光带** `.cv-steps::after`：横贯六步链、周期性扫过立方体后方的浅蓝亮带。

降级：`::before` 静态 opacity 0.45、`::after` 静态 opacity 0，全局 `prefers-reduced-motion` 关动画后停留在柔和静态，不出现常亮光柱或静止亮带遮挡。

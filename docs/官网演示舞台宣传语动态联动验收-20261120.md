# 官网演示舞台宣传语动态联动验收（2026-11-20）

## 需求
用户反馈：游客端、商户端的竖排宣传语和两个说明卡是静态写死的，不随视频演示切换栏目而变。截图里视频已经播到"旅行商城"，但标语还是"世界就是我的游乐场"、01 卡还是"发现一篇喜欢的笔记"，文不对图。要求文案跟随当前演示栏目动态切换。

## 实现
仅改 `招商宣传站/site/app.js`（视频交互 IIFE 内），HTML/CSS 不动：
- 新增 `STAGE_COPY` 文案表：游客端 5 栏（首页/主题游/商城/笔记/我的）、商户端 4 栏（工作台/订单/库存/我的），每栏配 `slogan` + 01/02 卡主副标题。
- `setStage(idx)` 取代原 `setActive`：先按 idx 高亮菜单，再用 `textContent` + `createTextNode`/`replaceChildren` 更新 `.demo-slogan`、`.demo-note-top span`、`.demo-note-bottom span`（保留 `<em>` 副标题结构）。`lastStage` 去重避免重复 DOM 写入。
- 两个触发点：① 点击 `[data-mini-tab]` → `setStage(i)`；② 视频 `timeupdate` → 按区间判定 `seek[i] <= t < seek[i+1]` 得 active → `setStage(active)`。视频自动播放时文案自动跟随。
- 严格 CSP 兼容：零内联样式、零 `element.style` 写入。

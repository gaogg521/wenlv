# B04 结算单元：确认成本回填 + 部分退款冲减进结算 + 平台资金桥表：实施与验收

> **2026-11-11 GLM 实施状态：实现完成／自测通过，待Codex独立验收。** 迁移 V78（settlement 加 cost_total/partial_deduct/bridge_snapshot；econ_bridge 快照表）。专项 `npm run test:settle` 5/5。本节不能替代 Codex 验收结论。

## 契约落点（在 V77 资金契约 v1 之上）

1. **确认成本回填**：订单进入结算（status=50 出账时点）即确认——`orders.cost_confirmed_fen = cost_total_fen`（B01 下单快照口径；未维护成本保持 NULL 不强填），结算单快照 `cost_total=Σ确认成本`。
2. **部分退款冲减进结算**：结算 total = Σ(实付−保费−已结算部分退款)。**状态机保证无"已结算后再部分退"**（部分退款仅限 20/30，结算需 50）→ 无需事后调整机制；结算单 `partial_deduct` 记录冲减额供对账。全退订单（70）不进结算（既有规则）。
3. **五口径恒等不受影响**：分摊比例作用于扣减后的 total，`amt_fulfill+amt_service+amt_promoter+amt_beanbudget+amt_retained=total_amount`（CHECK 约束+断言验证）。
4. **平台资金桥表**（`GET /admin/economics/bridge`，super/finance）：收入（总实收）→ 全退冲减 → 部分退款冲减 → 净销售额 → 直接成本（确认+预计分口径标注）→ 毛利 → 推广佣金 → 已知费用后经营收益；另列平台补贴责任与保费/代收款（不重复扣减：佣金与五口径 amt_promoter 同源、补贴已在实付中抵减）。每次查询落 `econ_bridge` 快照（只增不改）+ 内部恒等校验（balanceOk）。
5. **PC**：结算卡新增「确认成本 · 部分退款冲减 · 毛利（收入−成本）」行；资金工作台经营看板新增「资金桥表」弹窗。

## 契约算例（专项精确命中）

- 199 商品（门票12000 挂供给项+讲解7900 服务项）+ 满100减50 实付 14900：核销讲解项后退门票项 8984 → 结算 total = **5916**、partial_deduct = **8984**、确认成本 = **12000**、五口径恒等。
- 桥表：收入 14900 − 部分退 8984 = 净销售 5916；已退项成本同步冲减（12000→0，剩余项无成本）→ 毛利 5916 保留；收益 = 毛利 − 佣金；恒等校验平；负毛利/缺成本仍按 B01B12 口径展示。
- 全退订单：不进结算、确认成本不回填、桥表冲减为 0（实付原额）。

## 边界与后续

- 支付手续费：真实通道未接入，桥表费用行仅佣金（同源五口径）；接入后在此行追加，不另起口径。
- 已结算订单的cost 若后续人工调整（B01 依据变更）：走审计+新结算补充单，不改已出账单（既有规则）；当前未提供直接改确认成本入口。

# 官网合作共建区块重构验收（2026-11-20）

## 负责人反馈与处理

负责人指出「合作共建」模块设计效果差。原状为：居中通用标题 + 三张同款纯文字白卡（42px 线框图标）+ 一条与卡片脱离的四步细线链，缺少主题感、视觉锚点与图文层次。

处理口径：**原有 21 张摄影一张未替换**，只用新增独立照片；不改导航、不动业务数据；严格 CSP；不加外部脚本。

## 改动内容（PR #274）

- 区块头改为左右分栏社论式排版：左侧大标题，右侧合作逻辑说明 + 「发起合作咨询」入口，避免原来居中大留白。
- 三张合作对象卡重做为**摄影叙事卡**（01 目的地 / 02 在地商户 / 03 共创），每张包含：
  - 一张主题照片（顶部 228px，含渐变压暗与英文编号）；
  - 中文标题、对齐真实功能的说明；
  - 三枚能力标签（如场景梳理/主题预约/履约连接）；
  - 邮件 CTA，保留原有咨询邮箱与主题。
- 底部四步链重做为**深色闭环带**：中文序号节点、每步一句说明、一条横向导引线；手机改为单列节点列表。
- 新增三张 Pexels 原图（均为新增槽位，不复用、不替换原有照片）：
  - `partner-destination` photoId 36466085 —— 江南老巷夕阳，对应景区与目的地；
  - `partner-merchant` photoId 34222605 —— 中文招牌与灯笼的在地小店，对应当地商户；
  - `partner-creator` photoId 38113357 —— 上海滨江旅行者用手机记录城市，对应创作者与城市伙伴。
- 摄影白名单与校验脚本由 21 槽位扩至 **24 槽位**，新增槽位用 `partner-photo-img` 类做严格匹配，保持「一个槽位一张原图、文件字节不重复」的约束。

## 本地验收

- `node 招商宣传站/ops/check-photography.mjs`：24 槽位，原图唯一、文件唯一、引用一致，全部通过。
- `node --check app.js` 通过；无内联 `style` 属性、无 JS `element.style` 写入。
- CDP 精确视口量测 1440 / 390 / 320：`scrollWidth=innerWidth`，三档均无横向溢出。
- 320 宽初版出现「理由。」单字换行，已在 `max-width:360px` 下把标题字号收至 24px 并复测修正。
- 带生产同款 CSP 的验证页无内联样式违规；桌面四步带与手机单列节点截图确认排版整齐、无裁切/重叠。

# 商户徽章批量重设计

范围为徽章管理里的20枚商户徽章（63—82）：4枚等级认证、13枚经营荣誉、3枚可信经营徽章。圆拱认证牌采用暖铜、青榄、香槟金、林绿四级材质；经营荣誉使用珐琅圆章、大面积业务图形与轻量枝叶；可信经营采用林绿盾章，分别使用账册、盾牌和关联记录图形。去掉原有复杂屋檐吊绳、花结高光、霓虹网络装饰；等级点位与轮廓在小尺寸下仍可分辨。

图形接入既有后台统一徽章渲染器，输出SVG及小程序PNG。20枚图形及对应未获得灰阶均已导出在本目录证据中，可批量查看和单独取用。自定义上传图仍优先；图标键、主题色、四级材质和未获得状态继续支持。商户可信图根据 m_ 规则选择，游客可信徽章保留原形象。商户端与管理页图片增加版本参数，避免旧缓存继续显示旧图。

没有更改任何徽章定义、获得门槛、等级评定、实际归属、发放记录或存证状态；外观不表示新增认证资格。后台图形预览同步新增商户可信样例，商户等级说明更新为新材质。

验证：原徽章测试覆盖全部类别、稀有度和已获得/未获得、PNG输出、未知图标回退、等级与发放规则；新增商户/游客可信受众分离、未获得不带自定义色、异常tier安全回退检查。20枚×2状态通过实际PNG渲染。PR #144 合并为0015532后已同步演示工作区，保留原.env重启8080，健康检查正常；部署前备份 backup/merchant-warm-badges-before-deploy-20261108.sql。后台实际打开用户给出的 #badges，筛选商户徽章20行：20张图片加载、20张均采用新渲染，游客46号可信图仍为旧形象。40张公开PNG逐一请求全部200且宽256。

模拟器逐页走查再次通过，覆盖等级/勋章/凭证页签和我的入口，以及原订单、库存、结算和历史查询。首轮勋章墙截图发现图片短暂留白：每张PNG默认重复扫描全部系统字体，单张约237—266ms，批量时阻塞后续图片；这些图连国家代码也用路径绘制。关闭无需使用的字体扫描后样本降为2—4ms；四类图前后PNG逐字节相同。新增守护检查并保留原有PNG缓存，修复后补充冷启动勋章墙图片实际显示证据。[性能与一致性样本](evidence/merchant-badges-20261108/png-render.json)、[40图HTTP检查](evidence/merchant-badges-20261108/http-live.json)、[模拟器走查](evidence/merchant-badges-20261108/simulator-live.json)。

# 向往的自由 · 工程入口

先读这一页；接手开发（含 AI）请再读 [AI 交接手册](AI交接手册-20261102.md)。根目录下带日期的文档（`*-20261026.md` 等）是**历史记录**，用来追溯决策；当前状态以本页为准。

## 运行实现（唯一）

| 目录 | 是什么 |
|---|---|
| `api/` | Node 服务：游客端 `/c`、商户端 `/m`、后台 `/admin`、支付回调、公开复核页 `/verify`（路由按领域在 `api/src/routes/`） |
| `api/admin/` | PC 运营后台（零依赖 SPA，入口 `/admin-ui`）：`core.js` 公共层、`pages/` 各栏目、`workspace.js` 外壳 |
| `mini-a/` | 游客微信小程序 |
| `mini-b/` | 商户微信小程序 |
| `api/db/migration/` | 表结构迁移（V1–V35；V15/V16 编号空缺是历史原因，不是漏文件） |

不在运行链路上的内容：

- `server/`（Java）、`admin-web/`（Next.js）：历史备选实现，见各自 `ARCHIVED.md`
- `archive/`：已执行过的一次性补丁脚本，勿再运行
- `向往的自由-DOME设计原型源码/`、`招商宣传站/`：设计原型与宣传站（体积大，未来建议迁出主仓库或改用 Git LFS）

## 本地运行

```bash
cd api
npm ci
npm run migrate
JWT_SECRET=dev PASS_SECRET=dev npm start
```

后台：<http://127.0.0.1:8080/admin-ui>（首次启动的超管 `admin`，密码取 `ADMIN_INIT_PASSWORD`，默认 `admin123`，登录后修改）。

### 环境变量（除凭据外）

| 变量 | 作用 | 默认 |
|---|---|---|
| `DB_HOST` `DB_PORT` `DB_USER` `DB_PASS` `DB_NAME` | 数据库 | `127.0.0.1` / `3306` / `root` / `root` / `wanderlust` |
| `PUBLIC_BASE` | 对外访问基址（图片、复核链接、PDF 二维码）。真机/外网**必须**设置为 HTTPS 域名 | 按请求头推断 |
| `BIZ_TZ` | 业务时区：旅豆日终根、批次业务日按此切日 | `Asia/Shanghai` |
| `SECRETS_KEY` | 凭据加密主密钥（64 位十六进制）；未设置时由 `JWT_SECRET` 派生，**换 JWT_SECRET 会导致已保存凭据无法解密**。生产设置方法：`node scripts/secrets-key.mjs current` 取当前密钥原样设置；轮换用 `rotate` | — |

支付、小程序凭据在后台「集成中心」保存；**链凭据在后台「可信存证 → 链接入中心」保存**（均为 AES-256-GCM 加密落库，保存即生效，无需重启）。环境变量仍可用作兜底。

## 测试

```bash
cd api
npm test                                  # 语法 + import 路径 + Web3/退改/凭据密钥单元测试 + 小程序用语合规 + 小程序↔后台映射完整性（不碰数据库）
DB_NAME=wanderlust_qa npm run test:db     # 锚定终局、存证完整性、退改梯度、表单引擎、链接入中心、业务规则、内容审核、主体管理（需服务在跑，且与服务同一 JWT_SECRET）
DB_NAME=wanderlust_qa npm run seed:scenario   # 清库后按 28 步真实操作灌演示数据
```

会清空或改写数据的脚本（`seed:scenario`、`e2e`）带有数据库守卫：未设置 `DB_NAME` 或指向演示库 `wanderlust` 时**拒绝运行**。一次性容器内可设 `ALLOW_DESTRUCTIVE=1` 放行。

小程序页面巡检（`test/remediation-*.mjs`）依赖 Windows 上的微信开发者工具，操作要点见 [CLI 避坑手册](CLI调试-AI交接手册.md)。

## 后台能力速览

| 能力 | 入口 | 说明 |
|---|---|---|
| 资料编辑器 | 商品/团期/商户/景区/供应商/FAQ/轮播/勋章/推广服务商/旅豆预算/共创人/约稿/暗号/逐品佣金 | 字段定义集中在 `api/src/domain/entity-schema.mjs`，新增字段改一行配置 |
| 小程序装修与映射 | 小程序 → 装修与映射 | 小程序全部文案与配置可改；28 个页面逐项列出"在后台哪里改"，`npm test` 校验新页面必须登记 |
| 小程序用语合规 | 自动 | 小程序可见字段录入时拦截区块链/虚拟资产类词汇（词表 `domain/wording.mjs`）；`npm test` 扫描小程序源码与 `/c`、`/m` 接口返回 |
| 主体管理 | 用户与内容 → 用户中心；商户与进件 →「全景」；商品 →「数据」 | 用户分群/搜索/画像/冻结/风险，商户全景与商品数据；设计见 [后台管理体系设计](后台管理体系设计-20261102.md) |
| 链接入中心 | 可信存证 → 链接入中心 | 联盟链：链数根、腾讯云 TBaaS/至信链、蚂蚁链、FISCO BCOS、通用网关（长安链/BSN/星火·链网/百度超级链模板，HMAC-SHA256 / 国密 SM3）；公链：EVM（Ethereum/Polygon/Base/BNB/Arbitrum/Optimism/Conflux eSpace）。配置加密保存、离线自检、只读探测、输入标识确认后热切换；异步链回调 `POST /callback/chain/{gateway|chaingen}` |

## 可信存证（Web3）现状

| 能力 | 状态 |
|---|---|
| 7 类业务事件与业务同事务入队、状态演进多版本 | 已实现 |
| Merkle 批次 + inclusion proof + `prev_root` 存证链 | 已实现；新批次用 v2 算法（RFC 6962 域隔离），历史批次按 v1 继续可验证 |
| 旅豆账本日终根（借贷恒等才封存） | 已实现，按业务时区切日 |
| 公开复核页：浏览器本地重算 + 由公开载荷重算叶哈希 | 已实现 |
| 锚定上链 | 8 个适配器就绪（见链接入中心），**真实上链 0 笔**（未配置凭据，停在"已打包·待锚定"） |
| 锚定终局 | 需要确认的链（EVM）提交后为"已提交·待确认"，核验回执、确认数、交易内容后才记"已锚定" |

后台「可信存证 → 链路总览」用 3D 区块展示批次链，「演示 · 多节点形态」按钮可预览多区块效果（模拟数据，有明确标识）。

## 上线前仍需外部条件

1. 真实微信登录、JSAPI 扣款、公网 HTTPS 回调、实体相机扫码、退款到账：需要有效的 A/B AppID、商户号与支付平台配置，再做真机验收。
2. 结算是**人工支付回单登记**，不是电商收付通自动分账，不能对外宣传为自动结算。
3. 商城是到店预约/领取，不含配送与实物售后。
4. 真实上链需要链服务商凭据；拿到前不得对外称"已上链"。

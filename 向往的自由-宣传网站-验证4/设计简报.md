# 「向往的自由」宣传网站设计简报

> 版本 v1.0 · 2026-10-23 · 宣传策划师
> 素材来源：《向往的自由-业务系统demo-高保真版.html》（四端高保真原型 v1.12）＋《「向往的自由」Web3 文旅生态商业与技术总体方案》（demo 内引用口径）
> 用途：对外营销展示网站（Promotional Website）的设计与开发依据。**宣传站是营销叙事页，不是业务系统界面的复刻**——业务 demo 提供事实与素材，宣传站负责把它们翻译成大众听得懂、愿意传播的品牌故事。

## 一、从业务 demo 提炼的产品事实

### 1.1 产品定位
- **一句话定位**：「向往的自由」= Tourism Web3 OS，一个"四端一体"的文旅生态操作系统。
- **Slogan**：**世界就是我的游乐场**。
- **运营主体**：上海璟宬文化发展有限公司（合作旅行社作为收款主体）。
- **本质**（demo「关于」页原文口径）：Web3 负责确权、协作、记录与激励；真实旅游消费负责创造收入；平台通过提供服务获得利润——**不是单纯的旅游 App，也不是发币项目**。

### 1.2 四端一体架构

|---|---|---|---|---|
| A 层 | 游客端 | 橙 #E87722 | 会员消费生态 | 首页 / 主题游 / 商城 / 旅豆 / 我的 |
| B 层 | 合伙人端 | 蓝 #2F6F9F | 贡献经济共同体 | 收益 / 团队 / 邀请 / 我的 |

### 1.3 核心权益与技术概念（宣传时需"翻译"为用户语言）
| 概念 | 业务含义 | 宣传话术方向 |
|---|---|---|
| Travel ID | 统一数字身份：会员、旅行经历、数字凭证、隐私授权，一号四端通行 | "一个身份，走遍所有旅程"——你的旅行履历被永久记录 |
| Travel Pass | 链上发行、可核销可追踪的服务使用权 / 数字权益 / 数字成就凭证 | "门票即凭证"——行程凭证上链，真实可查、不会丢失 |
| 旅豆 | 链上权益凭证，人民币充值→权益兑换→核销结算；预算驱动发行 | "玩得越多，收获越多"——消费与贡献都能积攒成下次出行的权益 |
| 贡献分（CS） | 仅用于评级、推荐与服务激励，不对应股权/收益权 | （弱化数字细节，主打"贡献被看见、被奖励"） |
| 数字徽章/藏品 | 荣誉与权益凭证，不做二级交易炒作 | "可收藏的旅行纪念"——每一段经历都有一枚独一无二的徽章 |

### 1.5 生态闭环（可信度故事）
创作者发内容带归因链接获客 → 游客人民币下单 → 线下主题体验 → 平台核验贡献 → 按公式向商家 / 创作者 / 合伙人分账 → 旅豆权益回流 → 复购与裂变。

### 1.6 合规底线（宣传内容必须遵守）
- 旅豆 = 权益凭证，预算驱动发行；**不承诺任何投资回报**，不出现"币""投资""升值""分红"等表述。
- 境内旅豆与境外 Voyage Token 完全隔离；境外业务不进本次宣传主叙事。
- 合伙人只对真实服务和有效交易计酬——招募文案不得暗示"拉人头收益"。
- 所有经营数字在宣传站仅作示意，需标注"示例数据"。

## 二、宣传网站定位与目标受众

### 2.1 网站定位
- **性质**：品牌营销展示站（单站长滚动 + 少量二级页），承接品牌认知、产品种草、生态招募三类目标；**不做**登录、下单、核销等业务功能，转化出口指向"下载 App / 预约体验 / 商务合作表单"。
- **气质关键词**：自由、户外、温度、真实体验、信任科技。是"让人想去玩的旅行品牌"，Web3 只作为"幕后信任技术"露出，绝不做技术炫技主页。
- **一句话网站主张（Hero 备选）**：
  1. 世界就是我的游乐场（主推，与 App Slogan 一致）
  2. 把每一次出发，变成可以收藏的人生
  3. 玩得尽兴，收获更多——旅程结束时，你带走的比照片更多

### 2.2 目标受众与各自动机
| 受众 | 画像 | 动机 | 网站要给他的 |
|---|---|---|---|
| 核心游客（C 端） | 25–40 岁都市青年：白领女性（姐姐会/瑜伽）、单身青年（单身星球）、年轻家庭（亲子营）、剧本/潮玩爱好者（谜案社） | 想要"有主题、有社交、有纪念意义"的旅行，厌倦传统跟团 | 看得懂的玩法、真实线路、能晒的徽章与凭证 |
| 潜在合伙人 | 有本地资源/社群/内容能力的个人或小团队 | 靠谱的副业与事业机会，担心是传销/资金盘 | 清晰的分账逻辑、"只对真实交易计酬"的合规承诺 |
| 商家与目的地 | 景区、民宿、营地、研学基地、文旅集团 | 拉新与数字化升级 | 四端协同带来的订单、核销、对账工具与流量 |
| 内容创作者 | 旅行博主、本地达人 | 内容变现新路径 | 归因分账机制说明 + 招募入口 |
| 媒体/合作机构 | 需要引用权威口径 | 核实主体与合规 | 运营主体、方案出处、合规声明 |

### 2.3 转化目标（按优先级）
1. 游客：下载 App / 扫码预约体验线路
2. 合伙人・商家・创作者：填写合作意向表单
3. 全部：关注公众号/视频号，订阅线路上新

## 三、信息架构与页面结构

**总体结构建议**：1 个主长滚动页（品牌主场）＋ 3 个二级页（线路库、合作招募、关于我们），导航吸顶。移动端优先（业务主场景是手机），桌面端做栅格放大与横向叙事增强。

### 3.1 主页分区结构与文案要点

**S1 Hero 首屏（情绪定调）**
- 主标题：世界就是我的游乐场
- 副标题：向往的自由——主题旅行 × Web3 权益的新文旅生态。去朱家角破一桩江南谜案，去乌镇赴一场姐姐夜宴，去崇明篝火边认识新朋友；旅程结束，你带走的比照片更多。
- CTA：`探索主题旅程`（锚点到 S3）＋ `下载 App`（次要）
- 视觉：真实旅行摄影大图（篝火/古镇夜游/桨板日出），暖橙渐晕染，弱 Web3 元素。

**S2 信任条（首屏下方窄带）**
- 四个短徽标位：八大主题产品线 · Travel ID 一号通行 · 链上凭证可核验 · 正规主体运营（上海璟宬文化发展有限公司）
- 文案要点：一句话建立"新玩法 + 可信"的双重印象，不展开技术。

**S3 八大主题产品线（核心货架，权重最高）**
- 标题备选：总有一趟旅程，是为"现在的你"定制的
- 结构：8 张主题卡片（横滑或网格），每卡 = 子品牌名 + 主题色 + 1 张代表线路 + 一句玩法文案 + `查看线路`。
- 文案示例（每条线一句"钩子"）：
  - 谜案社：入戏即主角——实景搜证、NPC 对戏、多结局，把古镇玩成大型剧本现场
  - 姐姐会：和合拍的她们，把周末过成大片
  - 单身星球：认真玩，自然遇见——篝火、露营和刚好的心动
  - 瑜伽纪：在山野与湖面，把呼吸还给自己
  - 竞技场：出汗的快乐，需要对手与队友
  - 亲子营：孩子的自然课，全家的慢时光
  - 红色印记：走一段来时的路，上一堂走心的课
  - 世界线：把向往，延伸到国境之外

**S4 "玩得越多，收获越多"——权益玩法（Web3 的用户语言版）**
- 标题备选：旅程结束时，你带走的比照片更多
- 三步叙事（配手机场景插画/截图重绘，**不直接贴系统 UI 截图**）：
  1. **出发前**：报名即得 Travel Pass 电子凭证——链上发行、扫码核销，行程凭证真实可查、永不丢失
  2. **旅程中**：完成打卡与剧本任务、留下游记与影像，贡献被记录
  3. **旅程后**：获得旅豆与专属数字徽章——可兑换下一段旅程、联盟商家权益；你的旅行履历沉淀为一枚枚可收藏的纪念
- 底部小字合规注：旅豆为平台权益凭证，用于兑换服务与权益，不构成任何投资品。

**S5 一个身份，走遍所有旅程（Travel ID）**
- 标题备选：你的旅行人生，值得一个正式的身份
- 文案要点：手机号即可创建 Travel ID 数字身份；会员等级、旅行经历、数字凭证、隐私授权一号管理；游客、合伙人、商家四端数据互通（配 4 色端卡示意，呼应业务端配色但做营销化重绘）。
- 隐私承诺一句：位置、消费、偏好等数据授权均由你自主控制，可随时撤回。

**S6 生态如何运转（可信度叙事，面向 B 端受众）**
- 标题备选：一单旅行，让整个链条都被善待
- 内容：横向流程图（创作者获客 → 游客下单 → 线下体验 → 平台核验 → 多方分账 → 权益回流复购）；配三个角色小卡（商家按时拿到核销与对账、创作者按归因获得报酬、合伙人只对真实交易计酬）。
- 文案要点：强调"真实消费创造收入、透明规则分配利益"，为 S8 招募做铺垫。

**S7 真实的声音（社会证明）**
- 游客游记/徽章晒图 2–3 条（可用 demo 示例人设润色，上线前替换为真实授权内容）；合作目的地 logo 墙（朱家角、乌镇、井冈山红培中心等示例位）。
- 数据位（标注"示例数据"或上线前替换为真实口径）：主题线路数、合作商家数、覆盖城市数。

**S8 与我们同行（招募与转化，三条入口并列）**
- 成为游客：扫码下载 App，领新客权益
- 成为合伙人：本地资源/社群运营者，与平台共建城市站；只对真实服务与有效交易计酬，规则透明
- 成为商家/创作者：景区、民宿、营地、博主入驻，共享订单与分账
- 形态：三卡 + `提交合作意向` 表单（姓名/身份/城市/资源简述）。

**S9 合规与信任（短版，收尾前）**
- 四条铁律图标化：不发币、不承诺投资回报；权益预算驱动发行；境内境外业务独立隔离；正规旅行社主体收款。
- 一句来源注：产品设计依据《「向往的自由」Web3 文旅生态商业与技术总体方案》。

**S10 Footer**
- 品牌 + Slogan、公众号二维码、联系方式、ICP 备案位、运营主体全称、`关于我们`（跳二级页）、合规声明全文链接。

### 3.2 二级页
1. **线路库页**：按 8 大垂类筛选的线路卡片列表（复用 demo 线路数据结构：地点/天数/价格带/主题色），每条线路一个详情锚位：玩法亮点、行程速览、徽章权益、"下载 App 报名" CTA。**不放下单功能**。
2. **合作招募页**：合伙人/商家/创作者三类角色分别的"你将获得/你需要具备/合作规则"，附意向表单与合规承诺。
3. **关于我们页**：品牌故事、运营主体、四端架构图（营销化重绘）、媒体联系、完整合规声明。

## 四、视觉规范

### 4.1 色板
**品牌主色（沿用业务 demo，保证跨触点一致）**
| 角色 | 色值 | 用途 |
|---|---|---|
| 主色·日出橙 | `#E87722` | 主 CTA、Logo、强调、Hero 渐变起点 |
| 辅色·暖阳金 | `#F5A623` | 渐变终点、高亮、数字 |
| 深橙 | `#C25E10` | 橙色 hover/按下态 |
| 主色极浅底 | `#FFF3E8` | 橙系浅底块、标签底 |
| 墨蓝（沉稳锚） | `#243B55` | 深色区块、正文标题、夜景场景 |
| 纸白 | `#FFFFFF` | 卡片底 |
| 暖灰底 | `#F4F5F7` | 页面底色 |
| 正文灰 | `#4D5665` | 正文、次级信息 |
| 弱灰 | `#8A919C` | 辅助说明 |

**八主题线专属色**（用于产品卡与分区点缀，见 1.4 表）：`#7048E8 / #D6336C / #E85D75 / #0E9F8A / #1C7ED6 / #F59F00 / #C92A2A / #0C8599`。规则：同一视口最多出现 3 种主题色，其余用中性色压制，避免花哨。

**Web3 信任色（克制使用）**：链/凭证元素用墨蓝 `#243B55` + 青绿 `#0F9D58`（成功/已核销），仅以细线、图标、徽章形式出现，不做大面积渲染。

**对比度要求**：正文文字 ≥ 4.5:1；橙色底上一律白字加粗；浅橙底上用深橙/墨蓝文字。

### 4.2 字体
- 标题：PingFang SC / HarmonyOS Sans / Microsoft YaHei，**字重 800–900，字距 2–3px**（demo 登录页同款气势），可选用「思源黑体 Heavy」做数字与英文混排。
- 正文：PingFang SC Regular / Medium，15–17px，行高 1.7。
- 数字与英文点缀（旅豆数额、徽章编号）：DIN Alternate / Barlow Condensed / tabular-nums，体现"凭证感"。
- 排版基调：大标题 + 短段落；每屏一个主张；关键句用主题色下划线手绘笔触或浅橙高亮底。

### 4.3 组件与质感
- **卡片**：圆角 16–22px，白底，柔和投影 `0 8px 28px rgba(20,40,80,.12)`，悬停投影加深 + 上浮 4px（不做缩放位移抖动）。
- **渐变语言**：135° 品牌渐变（橙→金）用于 Hero 与 CTA；装饰元素为**半透明大圆环/圆**（demo hero 的标志性手法，沿用到宣传站形成家族感）。
- **按钮**：主按钮橙底白字、高度 ≥ 48px、圆角 13px；次按钮白底橙字细边框；全部 `cursor:pointer`，hover 只做颜色/阴影过渡 200ms。
- **徽章/凭证样式**：模拟"票根"造型——锯齿边或打孔 + tabular 数字 + 主题色描边；这是宣传站最具差异化的组件，用于权益区与用户晒图。
- **图标**：统一 24px viewBox 线性图标（Lucide/Heroicons 风格，与 demo 的 stroke 1.8 图标同族）；**禁止 emoji 当图标**。
- **图片/插画**：真实旅行摄影为主（暖调、逆光、人物真实互动），Web3 概念一律用扁平插画+线性图标表达；图片必须有 alt 文案。
- **导航**：吸顶玻璃拟态（白 92% + blur 14px，与 demo navbar 同语言），当前分区高亮橙色。

### 4.4 动效
- 原则：轻、快、有目的；全站遵守 `prefers-reduced-motion` 降级。
- 入场：分区间淡入 + 12px 上移，280ms ease-out，滚动触发一次性播放。
- 数字滚动：社会证明区的数字用 count-up（800ms，demo 同款）。
- 主题卡横滑：惯性滚动 + 边缘渐隐提示。
- 徽章获得/凭证核验示意：一次性印章盖章动效（scale 1.3→1 + 轻微旋转），用于权益区叙事。
- 页面切换与锚点滚动：平滑滚动，导航高亮同步。
